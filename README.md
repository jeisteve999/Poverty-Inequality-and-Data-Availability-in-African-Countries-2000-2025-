# Poverty-Inequality-and-Data-Availability-in-African-Countries-2000-2025-
This project analyzes poverty, income inequality, and data availability across African countries using World Bank indicators. The analysis includes data cleaning, transformation, validation, and exploratory analysis to identify socioeconomic patterns and assess data coverage.


# Data Source

Source: World Bank Open Data

link here: 

https://data.worldbank.org/topic/poverty

-Dataset: Poverty and Equity Database

-Coverage:

African Countries
Multiple poverty indicators
Income distribution indicators
Gini Index
Slum population indicators
Period: 2000–2025
